# Lapis Sync

Review pending changes, follow revisions across devices, compare file versions,
and resolve divergent edits inside the Lapis workspace. Sync keeps the history
and comparison controls together, including unified and split views.

End-to-end encryption is mandatory. Only enrolled endpoints can read vault
content. Device pairing and recovery controls keep secrets out of ordinary
plugin settings.

This plugin is currently a private preview. The catalog uses an injected
preview runtime; the Deno transport is still under development and these
screenshots do not demonstrate a live server connection.
