# Source inventory and attribution

Lapis Sync is licensed under Apache-2.0.

The following protocol sources are adapted from LapisMD's
`lapis-plugin-nostr-sync`, commit `665cf7f4`, whose source and package licensing
were corrected to Apache-2.0 at the user's request before extraction:

- `src/lib/adrs/decisions.ts`: retained versions, defaults and vault tags.
- `src/lib/crypto/canonical-json.ts`: canonical encoding.
- `src/lib/transport/types.ts`: event, filter and provider types.
- `src/lib/revisions/revision.ts`: encrypted revision/HEAD codecs and attestations.
- `src/lib/transport/authority-envelope.ts`: root attestation envelopes.
- `src/lib/sync/crypto-provider.ts`: opaque structural endpoint crypto interface.

Source-relative imports are adapted for the headless package. Signature
verification uses fresh event fields to avoid trusting cached verification on
mutable input. Filtering and replaceable ordering implement the agreed Deno
contract. Frozen wire fixtures were generated by the original source codecs;
their fixed keys are test-only and are not included in package artifacts.

Third-party libraries retain their respective license notices in the bundle.

The membership fixture qualifies root/outer transport attestations only. Host
membership ingestion, epoch envelopes and publication authority require their
own later acceptance; transport signature verification does not establish them.

The UI slice also adapts the same Apache-2.0 source revision: `src/lib/ui`
HistoryCanvas, RevisionGraph, SnapshotChangedFiles, ComparePane, SyncPanel,
SyncToolbar, SyncStatusBadge, PairingSettingsField, RecoverySettingsField,
revision-graph, snapshot-changes, history-format and their styles/tests;
`src/lib/nostr-sync-status.ts` and `src/lib/pairing-qr.ts`. Imports and CSS/test
names use the new Sync identity. Provider-neutral presentation, lifecycle,
settings and runtime actions are owned by this package. Source fixtures remain
test-only and are excluded from artifacts.

CompareToolbar is extracted from the retained ComparePane controls to support
the shared comparison header. SyncStatusPopover and the provider-neutral
workspace/settings composition are adapted for the public host contracts.

The durable engine also adapts `src/lib/objects/{manifests,object-graph}.ts`,
`src/lib/revisions/ancestry.ts`, `src/lib/sync/merge.ts` and
`src/lib/crypto/vault-crypto.ts` from that source revision. Local durability,
publication queue ordering and guarded snapshot creation are new implementations.

History membership authorization adapts the device-revocation, retired Sync
Identity and legacy-transport cutoff rules from `src/lib/sync/coordinator.ts`
at the same source revision. Lapis Sync requires enrolled host authority and
authenticated ancestry; the original missing-membership permissive fallback is
not retained.

Frozen object fixtures were emitted by the unchanged object/crypto/ADR sources
at commit `665cf7f4`. They preserve encrypted object bytes, hashes, manifest
encoding and stable file identities; fixed keys remain confined to test support.
