# Community

Community brings Lapis conversations, channels, and forums into a full
workspace view. Public rooms remain browseable without an identity; protected
actions request signing only when needed.

The host owns every credential. A locally created profile is saved in the
operating-system keychain, while remote accounts reconnect through NIP-46. The
plugin receives only opaque account details, signatures, and encrypted results.

The Registry destination uses the same host-configured Nostr relays, curator
keys, and quorum policy as the Lapis plugin screen. Install requests return to
the host plugin distribution manager, so browsing Community does not create a
second verification or installation path.
